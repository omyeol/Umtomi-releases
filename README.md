# Umtomi Android APK

Umtomi Android APK 배포 및 앱 업데이트 전용 저장소입니다.

[최신 APK 다운로드](https://github.com/omyeol/Umtomi-releases/releases/latest)

## 설치와 업데이트

1. 최신 릴리스의 `Umtomi-v버전-debug.apk`를 다운로드하여 설치합니다.
2. Umtomi 5.5.1부터 **설정 → 앱 버전(업데이트 확인)**에서 다음 업데이트를 확인하고 다운로드할 수 있습니다.
3. 설치 시 Android에서 Umtomi의 앱 설치 권한을 요청할 수 있습니다. 설치는 사용자가 확인해야 진행됩니다.

5.5.0 이하에서는 5.5.1 APK를 한 번 직접 설치해 주세요.
Android 5.0 이상을 지원합니다. 각 릴리스의 `SHA256SUMS.txt`로 파일 무결성을 확인할 수 있습니다.

이 저장소에는 APK와 배포 안내만 게시합니다.
